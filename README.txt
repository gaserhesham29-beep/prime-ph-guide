دليل الصيدلي — Prime PH
تطبيق ويب تقدمي (PWA) — إصدار رسمي من Rabtek
رقم الوثيقة: RBT-PH-POS-001 · الإصدار 1.0 · 25 أكتوبر 2026

المحتويات
----------
index.html              الدليل الكامل (الصور واللوجو مدمجة داخل الملف)
manifest.webmanifest    بيانات التطبيق (الاسم، الأيقونات، الألوان)
sw.js                   Service Worker للعمل بدون إنترنت
og-cover.png            صورة معاينة المشاركة على واتساب (1200×630)
robots.txt              منع فهرسة الوثيقة في محركات البحث
_headers                ترويسات MIME ومنع الفهرسة (Netlify / Cloudflare Pages)
icons/                  أيقونات التطبيق (192، 512، maskable، apple-touch، favicon)

طريقة النشر
------------
1. ارفع كل الملفات والمجلدات كما هي إلى مجلد على استضافة تدعم HTTPS،
   مثال: https://rabtek.net/prime-ph/
2. حافظ على أسماء الملفات وبنية المجلدات. لا تعِد تسمية sw.js أو manifest.webmanifest.
3. الرابط الذي ترسله على واتساب هو رابط المجلد نفسه:
   https://rabtek.net/prime-ph/
   ولا ترسل ملف index.html كمستند، لأن التثبيت يحتاج رابط HTTPS.

التثبيت على الهاتف
------------------
أندرويد (Chrome):
  افتح الرابط في Chrome ← قائمة ⋮ ← Install app أو Add to Home screen.

آيفون (Safari):
  افتح الرابط في Safari ← زر المشاركة ← Add to Home Screen ← Add.

ملاحظة: فتح الرابط من داخل واتساب لا يسمح بالتثبيت.
اضغط ⋮ أعلى الشاشة ثم Open in browser أولًا.

بعد النشر
---------
أرسل رابط المجلد إلى Rabtek لتحديث صورة المعاينة og:image إلى رابط مطلق،
حتى تظهر بطاقة الدليل الرسمية عند مشاركة الرابط على واتساب.
