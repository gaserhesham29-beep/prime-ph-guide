# دليل الصيدلي — Prime PH

تطبيق ويب تقدمي (PWA) رسمي من **Rabtek** لدليل تشغيل نقطة البيع في صيدلية Prime PH.

- **الرابط:** https://gaserhesham29-beep.github.io/prime-ph-guide/
- **رقم الوثيقة:** RBT-PH-POS-001
- **الإصدار:** 1.0 — 25 أكتوبر 2026

## التثبيت على الهاتف

**أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← Install app أو Add to Home screen.

**آيفون (Safari):** افتح الرابط ← زر المشاركة ← Add to Home Screen ← Add.

> فتح الرابط من داخل واتساب لا يسمح بالتثبيت. اضغط ⋮ ثم Open in browser أولًا.

## المحتويات

| الملف | الوظيفة |
|---|---|
| `index.html` | الدليل الكامل — الصور واللوجو مدمجة داخل الملف |
| `manifest.webmanifest` | بيانات التطبيق: الاسم والأيقونات والألوان |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `og-cover.png` | صورة معاينة المشاركة على واتساب (1200×630) |
| `robots.txt` | منع فهرسة الوثيقة في محركات البحث |
| `icons/` | أيقونات التطبيق |

## التحديث

يُولَّد `index.html` من مصدر الدليل، ثم يُدفع إلى فرع `main`، وينشر GitHub Pages التغيير تلقائيًا خلال دقيقة تقريبًا.
